## 4. 承認フロー完全シナリオ

### シナリオ1：SINGLE 通常承認通過

```
zhangsan が休暇申請を提出
  → 状態 PENDING、currentApproverId = admin（直属上司）
  → admin が承認 APPROVE
    → 状態 PENDING、currentApproverId = zongjian1（部門ディレクター）
    → zongjian1 が承認 APPROVE
      → 状態 APPROVED、フロー終了
```

### シナリオ2：途中却下

```
zhangsan が休暇申請を提出
  → admin が承認 REJECT
    → 状態 REJECTED、フロー終了
```

### シナリオ3：撤回

```
zhangsan が休暇申請を提出
  → zhangsan が撤回
    → 状態 WITHDRAWN
```

### シナリオ4：転送後に通過

```
zhangsan が休暇申請を提出
  → admin（直属上司）が zongjian2 に転送
    → 状態 PENDING、currentApproverId = zongjian2
    → zongjian2 が承認 APPROVE
      → 状態 PENDING、currentApproverId = zongjian1（部門ディレクター）
      → zongjian1 が承認 APPROVE
        → 状態 APPROVED
```

### シナリオ5：回覧全員通過（P2）

```
zhangsan が休暇申請を提出（回覧ノードあり：admin + zongjian1）
  → approval_task × 2 を作成（admin PENDING, zongjian1 PENDING）
  → admin が承認 APPROVE → admin タスク COMPLETED
    → 状態は PENDING のまま（zongjian1 が未完了）
  → zongjian1 が承認 APPROVE → zongjian1 タスク COMPLETED
    → 全員完了、次のノードに進行
```

### シナリオ6：合議クイック通過（P2）

```
zhangsan が休暇申請を提出（合議ノードあり：admin + zongjian1）
  → approval_task × 2 を作成（admin PENDING, zongjian1 PENDING）
  → admin が承認 APPROVE → admin タスク COMPLETED、zongjian1 タスク SKIPPED
    → 即時に次のノードに進行
```

### シナリオ7：条件分岐でノードスキップ（P2）

```
zhangsan が2日間の年次休暇を提出（条件ノード：days > 3）
  → 条件不成立 → 該当ノードをスキップ → 直接次のノードへ
```

### シナリオ8：タイムアウト自動エスカレーション（P2）

```
zhangsan が休暇申請を提出（ノード設定：1h + AUTO_APPROVE）
  → timeoutTime = now + 1h
  → 1時間後に TimeoutScheduler がタイムアウトをスキャン
    → 自動承認 → 次のノードに進行
```

## 5. APIテスト（curl サンプル）

### 5.1 ログインしてTokenを取得

```bash
curl -X POST http://localhost:8080/api/login \
  -H "Content-Type: application/json" \
  -d '{"username":"zhangsan","password":"123456"}'
```

### 5.2 申請提出

```bash
curl -X POST http://localhost:8080/api/leave/submit \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"templateId":1,"leaveType":"年假","startDate":"2026-06-01","endDate":"2026-06-03","reason":"test"}'
```

### 5.3 承認（通過）

```bash
curl -X POST http://localhost:8080/api/leave/approve \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"requestId":1,"action":"APPROVE","comment":"同意"}'
```

### 5.4 撤回

```bash
curl -X POST http://localhost:8080/api/leave/1/withdraw \
  -H "Authorization: Bearer <token>"
```

### 5.5 転送

```bash
curl -X POST http://localhost:8080/api/leave/1/transfer \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <token>" \
  -d '{"toUserId":3}'
```

### 5.6 並行タスク照会（P2）

```bash
curl -X GET http://localhost:8080/api/leave/1/tasks \
  -H "Authorization: Bearer <token>"
```

### 5.7 滞留修復（P2）

```bash
curl -X POST http://localhost:8080/api/leave/repair \
  -H "Authorization: Bearer <token>"
```

## 6. 回帰テストチェックリスト

- [ ] ログイン/ログアウト正常
- [ ] PENDING → APPROVE → 次のノードに進行（SINGLE）
- [ ] PENDING → REJECT → フロー終了
- [ ] PENDING → WITHDRAW → 状態変更
- [ ] PENDING → TRANSFER → 承認者変更
- [ ] 回覧：全員同意後に進行
- [ ] 回覧：拒否者ありで終了
- [ ] 合議：いずれか一名同意で進行
- [ ] 並行ノード撤回：全タスク SKIPPED
- [ ] 条件分岐：条件成立/不成立で正しく分流
- [ ] タイムアウト ESCALATE 転送
- [ ] タイムアウト AUTO_APPROVE 自動承認
- [ ] タイムアウト AUTO_REJECT 自動却下
- [ ] テンプレート CRUD + ノード設定（承認モード+条件+タイムアウト含む）正常
- [ ] 統計グラフ正常読み込み
- [ ] Excelエクスポートダウンロード可能
- [ ] 権限チェック有効（一般ユーザーはテンプレート管理不可）
- [ ] 滞留修復正常
