# Vue 3 + Vite

このテンプレートは、ViteでVue 3を使用した開発を始めるためのものです。このテンプレートはVue 3の`<script setup>` SFCを使用しています。詳しくは[script setup ドキュメント](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup)をご覧ください。

> 此模板可帮助您开始在 Vite 中使用 Vue 3 进行开发。该模板使用 Vue 3 的 `<script setup>` 单文件组件（SFC），请查阅 [script setup 文档](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) 了解更多。

VueのIDEサポートについて詳しくは、[Vue Docs Scaling up Guide](https://vuejs.org/guide/scaling-up/tooling.html#ide-support)をご覧ください。

> 了解有关 Vue 的 IDE 支持的更多信息，请参阅 [Vue 文档扩展指南](https://vuejs.org/guide/scaling-up/tooling.html#ide-support)。
