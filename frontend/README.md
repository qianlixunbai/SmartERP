# Vue 3 + Vite

このテンプレートは、Vite で Vue 3 を使用して開発を開始するのに役立ちます。このテンプレートは Vue 3 の `<script setup>` 単一ファイルコンポーネント（SFC）を使用します。詳細については [script setup ドキュメント](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) を参照してください。

Vue の IDE サポートの詳細については、[Vue ドキュメント拡張ガイド](https://vuejs.org/guide/scaling-up/tooling.html#ide-support) を参照してください。
